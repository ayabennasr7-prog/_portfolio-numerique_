💻 1. Les composants d'un ordinateur

  • Processeur (CPU) : exécute les instructions et effectue les calculs.
  • Mémoire RAM : conserve temporairement les données utilisées.
  • Disque dur / SSD : stocke les données durablement.
  • Carte mère : relie les différents composants.
  • Alimentation : fournit l'énergie électrique.

🔢 2. Les systèmes de numération

Un ordinateur utilise principalement le système binaire, composé de 0 et de 1.

Exemple : conversion binaire vers décimal

(1010)₂ = 1 × 8 + 0 × 4 + 1 × 2 + 0 × 1 = (10)₁₀

Exemple : conversion décimal vers binaire

(13)₁₀ = (1101)₂

Le système hexadécimal

Il utilise les chiffres de 0 à 9 et les lettres A à F.

(10)₁₀ = (A)₁₆
