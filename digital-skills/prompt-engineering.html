🤖 Prompt Engineering

L'art de communiquer efficacement avec l'intelligence artificielle !

✨ Qu'est-ce que le Prompt Engineering ?

Le Prompt Engineering est une technique qui consiste à formuler des instructions claires et précises pour guider une intelligence artificielle et obtenir des réponses pertinentes et adaptées à nos besoins.

🌷 Les 3 cas pratiques

📚 Cas 1 : Apprendre un cours

Prompt faible : Explique-moi Python.

Prompt amélioré : Agis comme un professeur d'informatique. Explique les bases de Python à un débutant avec des exemples simples et un petit exercice corrigé.

Analyse : Le deuxième prompt précise le rôle, le niveau et le format souhaité.

✍️ Cas 2 : Rédiger un texte

Prompt faible : Écris un texte sur l'environnement.

Prompt amélioré : Rédige un paragraphe de 150 mots sur la protection de l'environnement, avec une introduction, trois arguments et une conclusion, dans un français simple.

Analyse : Le deuxième prompt indique le sujet, la longueur, la structure et le niveau de langue.

🎨 Cas 3 : Créer une affiche

Prompt faible : Fais une affiche sur Internet.

Prompt amélioré : Propose le contenu d'une affiche éducative sur les dangers du partage des données personnelles. Utilise un titre accrocheur, cinq conseils pratiques et un style pastel rose et violet.

Analyse : Le deuxième prompt donne un objectif précis et des indications visuelles.

💡 Ma bibliothèque de 5 prompts

  1. Explique-moi une notion informatique avec des exemples faciles.
  2. Crée un programme Python simple et explique chaque ligne.
  3. Résume ce cours sous forme de fiche de révision.
  4. Propose cinq idées originales pour un projet étudiant.
  5. Corrige mon texte en expliquant mes erreurs.

📝 Mon bilan

Cette activité m'a permis de comprendre qu'un bon prompt doit être clair, précis et bien organisé. J'ai appris à améliorer mes instructions pour obtenir des réponses plus utiles de l'intelligence artificielle.

🤝 Utilisation de l'intelligence artificielle

L'intelligence artificielle a été utilisée pour proposer des exemples de prompts et améliorer leur formulation. J'ai étudié les résultats et organisé les exemples pour comprendre les différences entre un prompt faible et un prompt amélioré.
