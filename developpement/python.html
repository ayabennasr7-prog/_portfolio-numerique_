💻 Projet 1 : Calculatrice

Un programme qui permet d'effectuer les quatre opérations mathématiques.

a = float(input("Premier nombre : "))
b = float(input("Deuxième nombre : "))

print("Somme :", a + b)
print("Différence :", a - b)
print("Produit :", a * b)
if b != 0:
    print("Division :", a / b)
else:
    print("Division impossible")

🔢 Projet 2 : Nombre pair ou impair

Ce programme vérifie si un nombre est pair ou impair.

n = int(input("Donner un nombre : "))

if n % 2 == 0:
    print("Le nombre est pair")
else:
    print("Le nombre est impair")

🌸 Projet 3 : Table de multiplication

Ce programme affiche la table de multiplication d'un nombre.

n = int(input("Donner un nombre : "))

for i in range(1, 11):
    print(n, "x", i, "=", n * i)
