🌸 Algorithme 1 : Calculer la somme de deux nombres

Objectif : Calculer la somme de deux nombres.

Algorithme Somme
Variables a, b, s : réel
Début
    Lire(a, b)
    s ← a + b
    Écrire(s)
Fin

Exemple : a = 5, b = 3 → s = 8.

🔢 Algorithme 2 : Pair ou impair

Objectif : Vérifier si un nombre est pair ou impair.

Algorithme Pair_Impair
Variables n : entier
Début
    Lire(n)
    Si n MOD 2 = 0 Alors
        Écrire("Pair")
    Sinon
        Écrire("Impair")
    FinSi
Fin

Exemple : n = 7 → Impair.

✨ Algorithme 3 : Calculer une factorielle

Objectif : Calculer la factorielle d'un entier positif.

Algorithme Factorielle
Variables n, i, fact : entier
Début
    Lire(n)
    fact ← 1
    Pour i de 1 à n Faire
        fact ← fact * i
    FinPour
    Écrire(fact)
Fin

Exemple : n = 4 → 4! = 24.
